设置管理员口令

首位管理员的初始口令是由系统随机生成的,明文只在启动日志里出现过一次。 在这里用引导码重设一个你自己的口令。

{% if notice %}
{{ notice }}
{% endif %} {% if error %}
{{ error }}
{% endif %}

引导码就在服务器的 {{ code_file }} 文件里,整行复制即可(区分大小写)。 容器里可以这样读:docker compose exec calendar cat {{ code_file }}。

设置成功后引导码文件会被删除,这个地址也随之失效;忘记口令时用 python -m app.cli reset-admin-password 在服务器上重置。
